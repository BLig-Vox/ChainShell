# ChainShell ⛓️

**Your crypto. Your keys. Your terminal.**

ChainShell is a planned local-first crypto wallet manager with an interactive terminal interface (TUI). It aims to bring wallet management, balance checks, and transaction review to your terminal, with an encrypted local vault for sensitive wallet data.

## Planned features

- An interactive TUI for managing multiple wallets.
- A password-protected, encrypted local vault.
- Watch-only wallets using public addresses.
- Balance checks and transaction history.
- Explicit transaction review and confirmation before sending.
- Automatic vault locking after inactivity.

This repository currently contains only this introduction. No wallet or encryption functionality is implemented yet. Never add recovery phrases, private keys, or vault passwords to this repository or its issues.

We're just getting started. Stay tuned! 🚀
